# Propuesta completa de roster inicial

## Estado y propósito

Esta selección editorial de 151 **versiones** parte del conjunto aprobado el 2026-08-28 y suma a Deco (FC Porto 2003–04) el 2026-08-29 para cerrar la cobertura mínima de MC por contexto. Cumple cuotas de país y ciclo mundial, y no repite futbolistas. Las temporadas y clubes son candidatos concretos; la verificación de fuentes, la posición primaria definitiva, OVR, rasgos, secundarias e imágenes ocurren después de aprobar esta lista.

No es todavía el dataset activo ni una lista de valoraciones. Solo un error histórico verificable justifica reemplazar una identidad aprobada; los cambios de balance deben resolverse en OVR, rasgo o posición secundaria cuando sea posible.
