# Asignación editorial de OVR

## Estado

Primera propuesta completa de OVR para las 151 cartas de identidad ya aprobadas. Cada número es una valoración editorial propia del juego, no una importación de FIFA/EA ni una transformación automática de estadísticas. La asignación usa las seis anclas, comparación con pares de posición y época, y las bandas aprobadas.

Los valores siguen siendo revisables si la verificación histórica encuentra un error factual en la temporada o si las pruebas de draft muestran una distorsión de balance. No se deben alterar para resolver una cuota de país, posición o trait ya cubierta sin documentar el motivo.

## Próxima revisión necesaria
