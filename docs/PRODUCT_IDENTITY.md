# Identidad de producto — Once Draft

## Nombre vigente

El nombre público y editorial del proyecto es **Once Draft**.

Se usa en la interfaz, el título de la PWA, el manifest, el ícono accesible, la documentación canónica y el paquete raíz (`once-draft`). Su URL pública canónica es `https://oncedraft.vercel.app`. La propuesta comunica la idea central del producto: construir un once histórico a través de decisiones de draft.

## Convenciones

- `draft` continúa siendo el término de dominio para la secuencia de ofertas y elecciones del juego.
- Los paquetes internos `@draft/*`, claves de almacenamiento local, cookie de sesión, nombres de base de datos y volumen de desarrollo se conservan por compatibilidad. No son marca visible ni se modifican con este cambio. El caché del shell de la PWA sí recibe una nueva versión para entregar la marca actualizada a instalaciones existentes.
- El documento fuente conserva la procedencia de sus propuestas bajo el nombre `Game Design Document — Once Draft.pdf`.

## Alcance del cambio

Este cambio no altera reglas de juego, catálogo, cuentas, sesiones, datos guardados, API ni despliegues. Solo alinea la identidad pública y la documentación con **Once Draft**.
